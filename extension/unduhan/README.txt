Folder "unduhan" Ekstensi AI TTS Studio
======================================

Folder ini dikhususkan HANYA untuk:
1. File audio .wav asli yang diunduh otomatis oleh Ekstensi Chrome AI TTS Studio.
2. File audio .wav yang Anda masukkan/salin secara manual melalui File Manager / Windows Explorer.

Catatan Isolasi:
- Unduhan biasa/manual yang Anda lakukan langsung di Google AI Studio atau situs lain
  TIDAK akan dimasukkan ke folder ini dan tetap masuk ke folder unduhan normal browser Anda.
- Sambungkan folder "unduhan" ini satu kali di menu "Audio Library" pada website dashboard
  agar website selalu membaca & menyinkronkan file .wav asli dari folder ini secara otomatis.
